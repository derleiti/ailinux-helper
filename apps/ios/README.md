# AILinux Helper for iOS

> Current product status: iOS remains a design/build target of AILinux Helper 2.90.26, not a continuously-running background executor. Native distribution requires Apple signing/provisioning on macOS.

Native iOS companion design target. iOS preserves the durable workspace lease and reconnects when resumed; it does not claim a permanently running arbitrary WebSocket while suspended or force-quit. A signed IPA requires Apple signing credentials/provisioning and a macOS build host.
